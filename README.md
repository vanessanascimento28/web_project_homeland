# 🏠 Homeland – Sprint 5

Este projeto foi desenvolvido durante a Sprint 5 do curso Web Development da TripleTen. O desafio foi criar uma landing page responsiva baseada em um layout fornecido no Figma, representando as cidades natais de alguns membros da equipe TripleTen.
Neste sprint, o foco foi trabalhar com responsividade real utilizando **media queries**, organizar o código com **metodologia BEM**, conectar fontes externas localmente, aplicar práticas semânticas e ajustar o layout conforme diferentes resoluções (320px, 768px e 1280px).

**🎯 Objetivo do Projeto**

Construir uma página web responsiva baseada em um design fornecido no Figma, utilizando HTML e CSS puro. O projeto visa praticar conhecimentos de estrutura semântica, posicionamento com Flexbox, responsividade com media queries e boas práticas de organização de código com BEM.

**✅ Resultado**

A aplicação foi concluída com sucesso e publicada no GitHub Pages. A página se adapta corretamente a diferentes larguras de tela, mantendo fidelidade ao design original. Essa foi minha primeira experiência implementando um layout completo a partir de um protótipo real.

**🛠 Tecnologias Utilizadas**

- HTML5  
- CSS3  
- Flexbox  
- Google Fonts (Inter)  
- Metodologia BEM  
- Media Queries  
- Git e GitHub  
- GitHub Pages  

**⚙️ Funcionalidades**

- ✅ Layout totalmente responsivo para 320px, 768px e 1280px  
- ✅ Fontes conectadas localmente (Inter Web)  
- ✅ Semântica HTML aplicada corretamente  
- ✅ Organização com metodologia BEM  
- ✅ Publicação via GitHub Pages  


**🚀 O que aprendi com esse projeto**

- Interpretar e seguir um design do Figma
- Trabalhar com **breakpoints personalizados** e ajustes de layout por resolução  
- Organizar meu CSS com boas práticas e sem valores fixos excessivos  
- Otimizar imagens e aplicar `object-fit` para manter proporções visuais  
- Publicar meu projeto no GitHub Pages
